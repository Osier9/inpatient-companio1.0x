# 测试与验收规格说明

## 1. 测试策略

- 后端单元测试覆盖 Domain Service 的状态流转和权限规则。
- 后端接口测试覆盖 Controller 鉴权、参数校验和业务错误。
- 前端测试覆盖关键表单、路由守卫和状态展示。
- E2E 测试覆盖家属申请、管理员审核、护工执行、家属查看和评价主链路。

## 2. 阶段验收

| 阶段 | 验收重点 |
| --- | --- |
| Phase 00 | 工程可启动、数据库迁移可执行、接口统一响应 |
| Phase 01 | 登录、首次改密、账号启停、角色拦截 |
| Phase 02 | 患者新增、家属绑定、授权访问控制 |
| Phase 03 | 护工新增、编辑、停用、家属端查看护工 |
| Phase 04 | 家属申请、管理员确认/驳回、服务单创建 |
| Phase 05 | 排班创建、排班冲突、家属/护工查看排班 |
| Phase 06 | 模板维护、自定义任务、护工确认/退回/调整 |
| Phase 07 | 执行记录、图片上传、时间线、任务超时 |
| Phase 08 | 家属留言、护工回复、管理员内部备注 |
| Phase 09 | 通知生成、未读数、已读 |
| Phase 10 | 评价提交、重复评价拦截、护工评价脱敏 |
| Phase 11 | 工作台指标、待办和异常入口 |

## 3. 核心验收用例

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| AC-001 | 家属首次登录 | 强制进入修改密码页 |
| AC-002 | 家属提交陪护申请 | 生成待审核申请，管理员端出现待办 |
| AC-003 | 管理员确认申请 | 生成服务单、排班、固定任务和通知 |
| AC-004 | 排班冲突校验 | 同护工同日期同班次不可重复排班 |
| AC-005 | 家属新增自定义任务 | 护工端出现待确认任务 |
| AC-006 | 护工确认自定义任务 | 任务变为待执行，家属端同步 |
| AC-007 | 护工提交记录 | 任务变为已完成，家属时间线可见 |
| AC-008 | 护工跳过任务 | 必须填写原因，记录状态为已跳过 |
| AC-009 | 任务超时 | 超过计划时间 30 分钟未提交则标记已超时 |
| AC-010 | 家属查看未授权患者 | 返回无权限 |
| AC-011 | 家属留言 | 护工端出现未读留言 |
| AC-012 | 家属评价 | 管理员端可查看，护工端不展示家属手机号 |

## 4. 异常场景

| 场景 | 验收点 |
| --- | --- |
| 无授权患者 | 家属端展示联系机构提示 |
| 账号停用 | 用户不可登录 |
| 密码错误 5 次 | 账号锁定 15 分钟 |
| 申请驳回 | 家属端可见驳回原因 |
| 自定义任务退回 | 家属端可见原因并生成留言 |
| 图片上传失败 | 保留表单内容 |
| 图片无权限 | 不展示原图 |
| 留言发送失败 | 保留输入内容 |
| 重复评价 | 阻止提交并提示 |

## 5. 完成标准

- 所有 P0 模块验收通过。
- 主链路 E2E 通过：家属申请 -> 管理员确认 -> 排班 -> 任务 -> 护工记录 -> 家属查看。
- 权限隔离测试通过：家属、护工不能越权访问患者数据。
- 图片上传和访问鉴权测试通过。
- V1.0 范围外功能未被误实现为正式入口。
