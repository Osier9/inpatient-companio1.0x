# 后端设计规格说明

## 1. 后端总体设计

- 后端使用 Spring Boot 3.x。
- 按领域模块拆包，每个模块只暴露必要 Application Service。
- 所有写操作通过事务控制。
- 所有关键状态流转由后端校验，前端不能直接决定最终状态。

## 2. 包结构

```text
com.inpatientcompanio/

  auth/
  patient/

  notification/

  dashboard/
```

## 3. 通用后端能力

| 能力 | 说明 |
| --- | --- |
| 鉴权过滤器 | 校验 JWT，注入当前用户 |
| 角色注解 | ADMIN、FAMILY、CAREGIVER |
| 数据权限服务 | 校验家属患者授权和护工服务关系 |
| 统一异常 | 业务错误码和错误消息 |
| 审计日志 | 记录关键操作 |
| 事件发布 | 通知模块消费业务事件 |
| 文件服务 | 上传图片、生成签名访问地址 |

## 4. 阶段后端服务

| 阶段 | Application Service | Domain Service |
| --- | --- | --- |
| Phase 01 | AuthApplicationService、UserAdminService | PasswordService、PermissionService |
| Phase 02 | PatientApplicationService、FamilyAuthService | PatientAccessService |
| Phase 03 | CaregiverApplicationService | CaregiverStatusService |
| Phase 04 | CareRequestApplicationService、CareServiceOrderService | CareRequestDomainService |
| Phase 05 | ScheduleApplicationService | ScheduleDomainService |
| Phase 06 | CareTaskApplicationService、TaskTemplateService | CareTaskDomainService |
| Phase 07 | CareRecordApplicationService、ImageFileService | CareRecordDomainService |
| Phase 08 | MessageApplicationService | MessageAccessService |
| Phase 09 | NotificationApplicationService | NotificationDomainService |
| Phase 10 | ReviewApplicationService | ReviewDomainService |
| Phase 11 | DashboardQueryService | 无写状态流转 |

## 5. 关键业务规则

- 家属访问患者数据前必须校验授权关系。
- 护工访问患者数据前必须校验排班或服务单关系。
- 同一护工同一日期同一班次不可重复排班。
- 家属新增自定义任务后必须由护工确认才可执行。
- 已跳过执行记录必须填写原因。
- 图片访问必须通过业务权限校验。
- 服务单未结束不可评价。

## 6. 定时任务

| 定时任务 | 阶段 | 说明 |
| --- | --- | --- |
| TaskTimeoutJob | Phase 07 | 每 5 分钟扫描超过计划时间 30 分钟未提交的任务 |
| NotificationUnreadRefreshJob | Phase 09 | 可选，用于修复未读数缓存 |

## 7. 事件设计

| 事件 | 负载 |
| --- | --- |
| CareRequestSubmittedEvent | requestId、patientId、familyUserId |
| CareRequestApprovedEvent | requestId、serviceOrderId、familyUserId、caregiverId |
| ScheduleChangedEvent | scheduleId、patientId、caregiverId、familyUserId |
| TaskPendingConfirmEvent | taskId、caregiverId |
| TaskTimeoutEvent | taskId、patientId、caregiverId |
| MessageSentEvent | messageId、receiverUserId |
| ServiceEndedEvent | serviceOrderId、familyUserId |

## 8. 后端验收

- 所有接口具备角色鉴权。
- 所有跨角色数据读取具备数据权限校验。
- 状态非法流转返回业务错误。
- 审核、排班、任务记录、账号状态变更写入审计日志。
