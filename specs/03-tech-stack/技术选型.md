# 技术选型规格说明

## 1. 选型原则

- 优先选择成熟、易维护、适合中小型管理系统的技术。
- 首版支持快速开发和私有化部署。
- 避免引入支付、实时音视频、实时聊天等 V1.0 范围外能力。

## 2. 后端选型

| 类别 | 选型 | 用途 |
| --- | --- | --- |
| 语言 | Java 17 | 后端业务开发 |
| 框架 | Spring Boot 3.x | Web API、依赖注入、配置管理 |
| 安全 | Spring Security + JWT | 登录鉴权和角色拦截 |
| ORM | MyBatis Plus | CRUD、分页、条件查询 |
| 数据库迁移 | Flyway | 版本化管理表结构 |
| 参数校验 | Jakarta Validation | DTO 字段校验 |
| 定时任务 | Spring Scheduler | 任务超时扫描 |
| 文档 | OpenAPI/Swagger | API 调试和联调 |

## 3. 数据与基础设施

| 类别 | 选型 | 用途 |
| --- | --- | --- |
| 主库 | MySQL 8 | 业务数据 |
| 缓存 | Redis 7 | 登录失败计数、Refresh Token、未读数 |
| 对象存储 | MinIO | 陪护图片 |
| 部署 | Docker Compose | 本地和测试环境快速部署 |
| 日志 | Logback | 应用日志 |

## 4. 前端选型

| 类别 | 选型 | 用途 |
| --- | --- | --- |
| 框架 | Vue 3 | 管理端和 H5 |
| 语言 | TypeScript | 类型约束 |
| 构建 | Vite | 开发和构建 |
| 管理端 UI | Element Plus | 表格、表单、弹窗、分页 |
| H5 UI | Vant | 移动端表单、列表、Toast、Dialog |
| 状态管理 | Pinia | 用户态、患者切换、未读数 |
| HTTP | Axios | API 请求和拦截 |
| 图表 | ECharts | 工作台可选图表 |

## 5. 测试选型

| 类别 | 选型 | 用途 |
| --- | --- | --- |
| 后端单元测试 | JUnit 5 | Service、Domain 测试 |
| 后端接口测试 | Spring Boot Test | Controller 和权限测试 |
| 前端单元测试 | Vitest | 工具函数和组件逻辑 |
| E2E | Playwright | 关键流程验收 |

## 6. 阶段应用

- Phase 00 完成全部技术栈初始化。
- Phase 01 引入 Spring Security、JWT、Redis。
- Phase 04-07 强化事务、状态流转和定时任务。
- Phase 07 接入 MinIO。
- Phase 11 可按需要接入 ECharts，若时间紧张可只做数字卡片和列表。
