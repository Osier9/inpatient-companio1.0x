# 阶段与模块拆分规格说明

## 1. 拆分原则

- 必须按照模块功能进行阶段划分。
- 一个阶段不超过 1 个业务模块。
- 阶段依赖按最小可运行闭环推进，先基础能力，再业务主链路，再辅助能力。
- 每个阶段都应具备可验收输出，避免只完成底层代码但无法演示。

## 2. 阶段清单

| 阶段 | 模块 | 目标 | 核心需求编号 |
| --- | --- | --- | --- |
| Phase 00 | 基础工程 | 建立前后端工程、公共规范、环境配置 | NFR-001 至 NFR-008 |
| Phase 01 | 账号与权限 | 支持三类角色登录、首次改密、账号启停和权限拦截 | FAM-001、CAR-001、ADM-011 |
| Phase 02 | 患者与家属授权 | 管理患者资料和家属授权，建立数据权限边界 | ADM-003、ADM-004、EX-001 |
| Phase 03 | 护工管理 | 管理护工资料、账号、服务状态和家属端展示资料 | ADM-002、FAM-003、FAM-004 |
| Phase 04 | 陪护申请 | 家属提交申请，管理员确认/驳回，生成服务单 | BF-001 至 BF-008、FAM-005、ADM-005 |
| Phase 05 | 排班管理 | 创建排班，校验冲突，家属/护工查看排班 | BF-009 至 BF-013、ADM-006、CAR-002、CAR-008 |
| Phase 06 | 陪护任务管理 | 任务模板、家属自定义任务、护工确认/退回/调整 | BF-014 至 BF-022、FAM-006、FAM-007、CAR-003、CAR-004、CAR-006 |
| Phase 07 | 执行记录与图片 | 护工提交任务执行记录，家属和管理员查看时间线 | BF-023 至 BF-029、FAM-008、CAR-005 |
| Phase 08 | 留言管理 | 家属留言、护工回复、管理员查看和内部备注 | BF-030 至 BF-033、FAM-009、CAR-007、ADM-009 |
| Phase 09 | 站内通知 | 关键业务事件生成站内通知和未读提醒 | EX-006、NFR-002 |
| Phase 10 | 评价管理 | 家属评价护工，管理员处理评价，护工查看本人评价 | BF-034 至 BF-036、FAM-010、CAR-009、ADM-010 |
| Phase 11 | 管理员工作台 | 聚合待办、统计、异常提醒和快捷入口 | ADM-001 |

## 3. 推荐实施顺序

1. Phase 00 基础工程。
2. Phase 01 账号与权限。
3. Phase 02 患者与家属授权。
4. Phase 03 护工管理。
5. Phase 04 陪护申请。
6. Phase 05 排班管理。
7. Phase 06 陪护任务管理。
8. Phase 07 执行记录与图片。
9. Phase 08 留言管理。
10. Phase 09 站内通知。
11. Phase 10 评价管理。
12. Phase 11 管理员工作台。

## 4. 阶段验收边界

- Phase 00 只验收工程和公共能力，不验收业务流程。
- Phase 01 只验收登录、改密、账号状态和角色拦截。
- Phase 02 只验收患者、家属和授权关系。
- Phase 03 只验收护工资料和护工展示。
- Phase 04 只验收申请和服务单，不验收排班冲突。
- Phase 05 只验收排班，不验收任务执行。
- Phase 06 只验收任务计划和确认，不验收执行记录。
- Phase 07 只验收执行记录、图片和超时。
- Phase 08 只验收留言。
- Phase 09 只验收站内通知。
- Phase 10 只验收评价。
- Phase 11 只验收工作台聚合展示。
