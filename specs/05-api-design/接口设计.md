# 接口设计规格说明

## 1. API 规范

- 管理端 API 前缀：`/api/admin/**`
- 家属端 API 前缀：`/api/family/**`
- 护工端 API 前缀：`/api/caregiver/**`
- 通用 API 前缀：`/api/common/**`
- 分页参数：`pageNo`、`pageSize`
- 鉴权：除登录外，所有接口必须携带 Bearer Token。

## 2. 统一响应

```json
{
  "code": "0",
  "message": "success",
  "data": {}
}
```

```json
{
  "code": "AUTH_FORBIDDEN",
  "message": "暂无查看权限，请联系机构管理员",
  "data": null
}
```

## 3. Phase 01 账号与权限 API

| 方法 | 路径 | 角色 | 说明 |
| --- | --- | --- | --- |
| POST | `/api/common/auth/login` | 未登录 | 登录 |
| POST | `/api/common/auth/refresh` | 已登录 | 刷新 Token |
| POST | `/api/common/auth/logout` | 已登录 | 退出 |
| GET | `/api/common/auth/me` | 已登录 | 当前用户 |
| POST | `/api/common/auth/change-initial-password` | 已登录 | 首次改密 |
| POST | `/api/common/auth/change-password` | 已登录 | 修改密码 |
| POST | `/api/admin/users/{id}/reset-password` | ADMIN | 重置密码 |
| PATCH | `/api/admin/users/{id}/status` | ADMIN | 启用/停用 |
