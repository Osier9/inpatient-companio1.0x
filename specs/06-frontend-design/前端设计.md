# 前端设计规格说明

## 1. 前端总体设计

- 单仓库 Vue 3 + TypeScript + Vite。
- 管理端使用 PC Web 布局，家属端和护工端使用 H5 移动布局。
- 三端共用 API 客户端、类型定义、鉴权 Store 和错误处理。

```text
src/
```

## 3. 通用设计

- 路由守卫：未登录跳登录，首次未改密跳改密页，角色不匹配跳无权限页。
- 请求拦截：自动带 token。
- 响应拦截：401 清登录态，403 展示无权限，业务错误 Toast。
- 表单失败保留输入内容。
- H5 页面首屏控制请求数量，避免一次加载全部业务数据。

## 8. 前端验收

- 三端路由可按角色访问。
- 首次登录未改密时不可进入业务页面。
- 家属端无授权患者显示空状态。
- 护工端无排班显示空状态。
- 图片上传失败、留言失败、申请驳回均有明确反馈。
