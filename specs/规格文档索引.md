# 住院陪护系统规格文档索引

本目录按规格主题拆分，而不是按模块重复编写完整规格文档。模块阶段仍按功能拆分，确保每个阶段不超过 1 个业务模块。

## 阶段划分

| 阶段 | 模块 | 说明 | 依赖 |
| --- | --- | --- | --- |
| Phase 00 | 基础工程 | 工程初始化、公共规范、环境配置 | 无 |
| Phase 01 | 账号与权限 | 登录、首次改密、账号状态、角色权限 | Phase 00 |
| Phase 02 | 患者与家属授权 | 患者资料、家属账号、授权绑定 | Phase 01 |
| Phase 03 | 护工管理 | 护工资料、工号账号、服务状态 | Phase 01 |
| Phase 04 | 陪护申请 | 家属申请、管理员审核、服务单创建 | Phase 02、Phase 03 |
| Phase 05 | 排班管理 | 排班创建、冲突校验、排班查看 | Phase 04 |
| Phase 06 | 陪护任务管理 | 固定模板、自定义任务、任务确认 | Phase 05 |
| Phase 07 | 执行记录与图片 | 任务记录、图片上传、时间线、超时 | Phase 06 |
| Phase 08 | 留言管理 | 家属留言、护工回复、管理员备注 | Phase 05 |
| Phase 09 | 站内通知 | 通知生成、未读数、已读状态 | Phase 04-08 |
| Phase 10 | 评价管理 | 服务评价、护工评价查看、回访标记 | Phase 05 |
| Phase 11 | 管理员工作台 | 统计指标、待办、异常和快捷入口 | Phase 04-10 |
