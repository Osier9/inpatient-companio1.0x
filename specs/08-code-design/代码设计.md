# 代码设计规格说明

## 1. 命名规范

- Controller：`XxxController`
- Application Service：`XxxApplicationService`
- Domain Service：`XxxDomainService`
- Repository：`XxxRepository`
- Entity：`XxxEntity`
- DTO 入参：`XxxRequest`
- DTO 出参：`XxxResponse`
- 列表项：`XxxItem`
- 枚举：`XxxStatus`、`XxxType`

## 2. 模块代码结构

```text
module/
  controller/
  application/
  domain/
  repository/
  dto/
  entity/
```

## 3. 通用对象

```java
class ApiResponse<T> {
  String code;
  String message;
  T data;
}
```

```java
class PageResponse<T> {
  long total;
  int pageNo;
  int pageSize;
  List<T> records;
}
```

## 6. 前端代码规范

- 页面组件只处理 UI 状态，不直接拼接接口路径。
- API 请求统一放在 `shared/api`。
- 类型统一放在 `shared/types`。
- Store 只保存跨页面状态，例如用户、角色、当前患者、未读数。
- 表单校验规则靠近页面定义，复杂规则抽到 `shared/utils/validators`。

## 7. 后端代码规范

- Controller 不写业务逻辑。
- Repository 不写业务规则。
- 状态流转只允许 Domain Service 修改。
- 跨模块读写必须通过 Application Service 或领域服务方法。
- 事务边界放在 Application Service。
- 审计日志通过注解或应用服务显式调用。
