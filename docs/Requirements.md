## 2. 项目概述

住院陪护系统面向陪护机构内部使用，帮助机构管理护工、患者、家属授权、陪护申请、排班、任务、陪护记录、留言和评价。患者家属可在机构内自由选择护工并发起陪护申请；管理员确认后生成服务单和排班；护工按固定任务和自定义任务进行陪护记录；家属查看执行情况并进行留言和评价。

V1.0 不包含支付、退款、发票、视频监控、实时定位、实时聊天、短信/微信外部通知、医院系统对接、护工薪资结算等能力。

## 3. 用户与权限

| 角色 | 登录方式 | 核心能力 | 权限边界 |
| --- | --- | --- | --- |
| 管理员 | 后台账号+密码 | 管理机构数据、审核申请、排班、查看记录和评价 | 可管理机构内全部业务数据 |
| 家属 | 手机号+密码 | 选择护工、提交申请、添加任务、查看记录、留言、评价 | 仅可访问已授权患者相关数据 |
| 护工 | 工号+密码 | 查看排班、确认任务、提交记录、上传图片、回复留言 | 仅可访问本人排班患者相关数据 |

### 3.1 通用账号规则

- 管理员创建家属账号和护工账号，并设置初始密码。
- 家属首次登录后必须修改密码，未修改前不可进入业务页面。
- 护工首次登录后必须修改密码，未修改前不可进入业务页面。
- 密码长度为 8-20 位，必须同时包含字母和数字。
- 连续 5 次登录失败后，账号锁定 15 分钟。
- 账号停用后不可登录；已登录账号再次请求业务接口时应被拦截。

## 4. 业务流程需求

### 4.1 陪护申请流程

| 编号 | 需求 |
| --- | --- |
| BF-001 | 家属选择已授权患者后，可浏览机构内护工列表。 |
| BF-002 | 家属可按护工性别、评分、服务状态筛选护工。 |
| BF-003 | 家属可查看护工详情，包括头像、姓名、经验、擅长、评分、近期评价和可申请状态。 |
| BF-004 | 家属提交陪护申请时必须填写患者、目标护工、服务开始日期、服务结束日期、班次和需求说明。 |
| BF-005 | 申请提交后状态为“待审核”，管理员端产生待办通知。 |
| BF-006 | 管理员可确认、驳回或调整陪护申请。 |
| BF-007 | 管理员确认申请时，系统生成服务单、排班、固定任务和站内通知。 |
| BF-008 | 管理员驳回申请时必须填写驳回原因，家属端可查看。 |

### 4.2 排班流程

| 编号 | 需求 |
| --- | --- |
| BF-009 | 管理员可按日期、护工、患者、班次查看排班。 |
| BF-010 | 同一护工同一日期同一班次不可重复排班。 |
| BF-011 | 排班必须关联服务单、患者和护工。 |
| BF-012 | 管理员调整排班后，家属端和护工端应同步展示新排班。 |
| BF-013 | 已结束或已中止服务单不可新增排班。 |

### 4.3 陪护任务流程

| 编号 | 需求 |
| --- | --- |
| BF-014 | 管理员维护机构级固定任务模板。 |
| BF-015 | 服务单生成后，系统根据启用的固定任务模板初始化任务计划。 |
| BF-016 | 家属可为服务中患者新增自定义任务。 |
| BF-017 | 家属新增自定义任务后，任务状态为“待确认”。 |
| BF-018 | 护工可确认、退回或建议调整家属新增的自定义任务。 |
| BF-019 | 护工确认后，自定义任务进入待执行状态。 |
| BF-020 | 护工退回或建议调整时必须填写原因，并生成留言通知家属。 |
| BF-021 | 护工可添加临时任务，提交后家属端可见。 |
| BF-022 | 自定义任务页面需展示提示：请以医护人员医嘱为准，系统仅用于陪护任务提醒和记录。 |

### 4.4 执行记录流程

| 编号 | 需求 |
| --- | --- |
| BF-023 | 护工可对待执行任务提交执行记录。 |
| BF-024 | 执行状态包括“已完成”和“已跳过”。 |
| BF-025 | 已完成记录需填写实际执行时间，可填写备注，可上传图片。 |
| BF-026 | 已跳过记录必须填写跳过原因。 |
| BF-027 | 图片最多上传 3 张，单张大小不超过 10 MB，格式支持 JPG、PNG。 |
| BF-028 | 超过计划执行时间 30 分钟未提交时，任务自动标记为“已超时”。 |
| BF-029 | 执行记录提交成功后，家属端记录时间线应同步展示。 |

### 4.5 留言与评价流程

| 编号 | 需求 |
| --- | --- |
| BF-030 | 家属可针对当前服务单向护工留言。 |
| BF-031 | 护工可回复本人服务单相关留言。 |
| BF-032 | 管理员可查看留言，并可添加内部处理备注。 |
| BF-033 | 管理员内部备注不展示给家属和护工。 |
| BF-034 | 服务单结束后，家属可对护工提交一次评价。 |
| BF-035 | 评价包含评分、评价标签和文字评价。 |
| BF-036 | 护工端可查看本人评价，但不展示家属手机号。 |

## 6. 数据字段要求

### 6.1 必填字段

| 对象 | 必填字段 |
| --- | --- |
| 用户 | 角色、姓名、登录账号、初始密码、账号状态 |
| 患者 | 姓名、性别、年龄、医院、科室、床号、状态 |
| 护工 | 姓名、工号、手机号、服务状态、账号状态 |
| 陪护申请 | 患者、家属、目标护工、服务开始日期、服务结束日期、班次 |
| 服务单 | 申请、患者、护工、服务日期范围、服务状态 |
| 排班 | 服务单、护工、患者、日期、班次 |
| 任务 | 患者、任务名称、计划执行时间、执行方式、任务来源、任务状态 |
| 执行记录 | 任务、执行人、执行状态、实际执行时间、提交时间 |
| 留言 | 服务单、发送人、内容、发送时间 |
| 评价 | 服务单、家属、护工、评分、提交时间 |

### 6.2 关键枚举

| 枚举 | 取值 |
| --- | --- |
| 申请状态 | 待审核、已确认、已驳回、已取消 |
| 服务单状态 | 待开始、服务中、已结束、已中止 |
| 任务状态 | 待执行、待确认、已确认、需调整、已完成、已跳过、已超时 |
| 任务来源 | 固定模板、家属自定义、护工临时 |
| 执行状态 | 已完成、已跳过 |
| 账号状态 | 启用、停用、锁定 |
| 通知类型 | 申请待审核、申请确认、申请驳回、排班变更、任务待确认、任务超时、留言未读、服务结束待评价 |

## 7. 非功能需求

| 编号 | 类型 | 需求 |
| --- | --- | --- |
| NFR-001 | 性能 | 移动端首屏加载目标小于 3 秒，后台常用列表查询目标小于 2 秒。 |
| NFR-002 | 可用性 | 列表页支持分页或下拉加载；表单提交失败时保留已输入内容。 |
| NFR-003 | 安全 | 登录、业务接口、图片访问均需鉴权；密码不得明文存储。 |
| NFR-004 | 权限 | 家属、护工、管理员按角色和数据归属进行访问控制。 |
| NFR-005 | 审计 | 登录、密码修改、排班调整、审核申请、提交记录、账号停用需记录操作日志。 |
| NFR-006 | 文件 | 图片上传支持 JPG、PNG，单张不超过 10 MB，每条记录最多 3 张。 |
| NFR-007 | 兼容 | 管理后台适配主流桌面浏览器；H5 适配常见手机浏览器和微信内置浏览器。 |
| NFR-008 | 隐私 | 患者健康相关信息按敏感个人信息处理，遵循最小必要和授权访问原则。 |

## 8. 异常与边界场景

| 编号 | 场景 | 系统处理 |
| --- | --- | --- |
| EX-001 | 家属无授权患者 | 首页展示无授权提示，不展示任何患者业务数据。 |
| EX-002 | 首次登录未改密 | 强制跳转修改密码页，改密成功后进入业务页面。 |
| EX-003 | 护工排班冲突 | 管理员保存排班时阻止提交，并展示冲突排班信息。 |
| EX-004 | 申请被驳回 | 家属端展示驳回状态和原因。 |
| EX-005 | 自定义任务被退回 | 家属端展示退回原因，并在留言中生成沟通记录。 |
| EX-006 | 任务超时 | 任务状态变为已超时，并生成站内通知。 |
| EX-007 | 图片上传失败 | 保留表单内容，提示重新上传或稍后重试。 |
| EX-008 | 图片无权限访问 | 展示无权限提示，不展示原图。 |
| EX-009 | 留言发送失败 | 保留输入内容，提示重试。 |
| EX-010 | 重复评价 | 阻止提交，并提示该服务单已评价。 |

## 9. 验收用例

| 编号 | 用例 | 前置条件 | 操作 | 预期结果 |
| --- | --- | --- | --- | --- |
| AC-001 | 家属首次登录改密 | 管理员已创建家属账号 | 家属用手机号和初始密码登录 | 系统强制进入修改密码页 |
| AC-002 | 家属提交陪护申请 | 家属已绑定患者 | 选择护工并提交申请 | 生成待审核申请，管理员端出现待办 |
| AC-003 | 管理员确认申请 | 存在待审核申请 | 选择护工、日期、班次和任务模板后确认 | 生成服务单、排班、固定任务和通知 |
| AC-004 | 排班冲突校验 | 护工已有同班次排班 | 管理员再次安排同一班次 | 系统阻止保存并提示冲突 |
| AC-005 | 家属新增自定义任务 | 服务单状态为服务中 | 家属填写任务并提交 | 护工端出现待确认任务 |
| AC-006 | 护工确认自定义任务 | 存在待确认任务 | 护工点击确认 | 任务变为待执行，家属端同步状态 |
| AC-007 | 护工提交任务记录 | 存在待执行任务 | 填写实际时间、备注并上传图片 | 任务变为已完成，家属端时间线可见 |
| AC-008 | 护工跳过任务 | 存在待执行任务 | 选择已跳过并填写原因 | 任务变为已跳过，记录原因 |
| AC-009 | 任务超时提醒 | 任务超过计划时间 30 分钟未提交 | 系统定时检查 | 任务变为已超时并生成站内通知 |
| AC-010 | 家属查看记录权限 | 家属未绑定某患者 | 尝试查看该患者记录 | 系统拒绝访问并提示无权限 |
| AC-011 | 家属留言 | 服务单服务中 | 家属发送文本留言 | 护工端出现未读留言 |
| AC-012 | 家属评价 | 服务单已结束 | 家属提交评分和文字评价 | 评价保存，管理员端可查看 |

## 10. 交付物与评审建议

- 需求评审建议按“业务闭环页 -> 家属端 -> 护工端 -> 管理员端 -> 权限与异常”的顺序演示。
- 研发拆分建议优先级：账号权限、患者家属绑定、护工管理、申请审核、排班、任务与记录、留言、评价。
- 测试编写建议以第 9 章验收用例为主线，再补充表单校验、权限隔离和异常处理。
- 甲方确认时需重点确认：班次定义、固定任务模板内容、任务超时阈值、图片保存周期、评价是否对护工可见。
