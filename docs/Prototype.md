# 住院陪护系统原型说明

## 1. 原型目标

本原型说明用于指导 UI 设计和前端开发，覆盖管理员 PC 后台、患者家属 H5、护工 H5 三端首版页面。原型优先表达业务流程、页面入口、主要组件、交互反馈、空状态与异常状态，不包含视觉稿细节和可点击 HTML 实现。

## 2. 信息架构

| 陪护申请 | 申请列表、申请详情、审核弹窗 |

## 3. 管理员端页面说明

### 3.1 登录页

- 入口：后台访问地址。
- 组件：账号输入框、密码输入框、登录按钮、错误提示。
- 交互：
  - 账号或密码为空时，按钮点击后展示表单校验。
  - 登录失败展示原因；连续失败达到限制时提示锁定时间。
  - 首次登录账号进入修改密码页。
- 空/异常：
  - 网络异常提示“登录失败，请稍后重试”。

### 3.2 工作台

- 入口：管理员登录后默认页。
- 组件：数据概览卡片、待审核申请列表、今日排班列表、超时任务列表、待处理留言、近期评价。
- 关键字段：
  - 今日排班数、服务中患者数、在岗护工数、超时任务数、待处理申请数。
- 交互：
  - 点击待审核申请进入申请详情。
  - 点击超时任务进入陪护记录详情。
  - 点击留言进入留言详情。
- 空/异常：
  - 无待办时展示空状态“暂无待处理事项”。

### 3.3 护工管理

- 护工列表
  - 组件：筛选区、表格、分页、新增护工按钮。
  - 筛选：姓名/工号、性别、服务状态、账号状态、评分区间。
  - 表格字段：头像、姓名、工号、手机号、经验年限、擅长、评分、服务状态、账号状态、操作。
  - 操作：查看、编辑、重置密码、停用/启用。
- 护工详情
  - 组件：基础资料、服务统计、当前排班、历史服务、评价列表。
  - 交互：编辑后返回详情并刷新数据。
- 新增/编辑护工
  - 字段：姓名、工号、手机号、性别、年龄、经验年限、擅长、简介、照片、账号状态、初始密码。
  - 校验：工号唯一；手机号格式正确；初始密码符合规则。

### 3.4 患者管理

- 患者列表
  - 筛选：患者姓名、医院、科室、床号、服务状态。
  - 字段：姓名、性别、年龄、医院、科室、床号、授权家属数、当前护工、服务状态、操作。
- 患者详情
  - 组件：基础信息、护理注意事项、授权家属、当前服务、历史记录。
  - 操作：编辑患者、绑定家属、停用授权。
- 家属绑定
  - 字段：家属姓名、手机号、与患者关系、初始密码。
  - 交互：可绑定已有家属账号；手机号不存在时创建账号。

### 3.5 陪护申请审核

- 申请列表
  - 筛选：申请状态、患者、家属、目标护工、申请日期。
  - 字段：申请编号、患者、家属、目标护工、期望日期、班次、状态、提交时间、操作。
- 申请详情
  - 展示：患者信息、家属信息、目标护工、需求说明、历史申请。
  - 操作：确认、驳回、取消。
- 审核弹窗
  - 确认字段：最终护工、服务日期、班次、任务模板、备注。
  - 驳回字段：驳回原因。
  - 反馈：确认成功后生成服务单、排班和站内通知。

### 3.6 排班管理

- 页面结构：顶部筛选、日历/列表切换、排班卡片、排班详情侧栏。
- 筛选：日期、护工、患者、班次、服务状态。
- 交互：
  - 日历中点击排班卡片打开详情。
  - 调整护工或班次时校验冲突。
  - 调整成功后通知家属和护工。
- 异常：
  - 护工同班次冲突时阻止保存并展示冲突排班。

### 3.7 任务模板

- 列表字段：任务名称、任务类型、默认执行时间、执行要求、启用状态、更新时间。
- 操作：新增、编辑、启用/停用。
- 编辑规则：模板停用不影响已生成任务。
- 空状态：无模板时引导新增固定任务。

### 3.8 陪护记录

- 列表筛选：患者、护工、日期、任务类型、任务状态。
- 列表字段：患者、护工、任务名称、计划时间、实际执行时间、状态、图片数、备注摘要。
- 详情展示：任务信息、执行记录、图片预览、提交人、提交时间。
- 异常：图片加载失败时展示占位和重试入口。

### 3.9 留言管理

- 列表字段：患者、服务单、发送人、接收角色、最后留言、未读状态、发送时间。
- 详情展示：留言上下文、回复记录、管理员内部备注。
- 操作：标记已处理、添加备注。
- 权限：管理员备注不展示给家属和护工。

### 3.10 评价管理

- 列表字段：服务单、患者、护工、评分、标签、评价内容、提交家属、提交时间、处理状态。
- 操作：查看详情、标记需回访、标记已处理。
- 护工隐私：护工端评价不展示家属手机号。

### 3.11 系统设置

- 账号管理：管理员账号、家属账号、护工账号列表。
- 操作：新增管理员、重置密码、停用/启用账号。
- 角色权限：V1.0 预设管理员、家属、护工三类角色，不提供自定义角色。

## 4. 家属端 H5 页面说明

### 4.1 登录与首次改密

- 登录组件：手机号、密码、登录按钮。
- 首次改密组件：原密码、新密码、确认密码、提交按钮。
- 交互：
  - 首次登录强制进入改密页。
  - 修改成功后进入首页。
  - 密码不符合规则时展示即时校验。

### 4.2 首页

- 组件：患者切换、当前服务卡片、今日任务摘要、站内提醒、快捷入口。
- 当前服务卡片字段：患者、医院科室床号、当前护工、服务日期、班次、服务状态。
- 今日任务摘要：待执行、待确认、已完成、已超时数量。
- 快捷入口：查看记录、添加任务、联系护工、评价。
- 空状态：
  - 无授权患者：提示联系机构绑定患者。
  - 无当前服务：展示“暂无进行中的陪护服务”，保留护工列表入口。

### 4.3 护工列表

- 组件：搜索框、筛选、护工卡片。
- 护工卡片字段：头像、姓名、性别、经验年限、擅长、评分、服务状态。
- 操作：查看详情、提交申请。
- 空状态：无匹配护工时提示调整筛选条件。

### 4.4 护工详情

- 展示：头像、姓名、经验、擅长、简介、近期评价、服务状态。
- 主按钮：申请陪护。
- 交互：
  - 不可申请状态时按钮置灰并说明原因。
  - 点击申请进入陪护申请页。

### 4.5 陪护申请

- 字段：患者、目标护工、服务开始日期、服务结束日期、班次、需求说明。
- 提交后：进入申请详情，状态为待审核。
- 校验：
  - 必须选择患者、日期和班次。
  - 结束日期不能早于开始日期。
- 状态展示：待审核、已确认、已驳回、已取消。

### 4.6 任务计划

- 入口：首页今日任务摘要、记录页顶部。
- 组件：日期选择、任务列表、添加自定义任务按钮。
- 任务卡片字段：任务名称、计划时间、执行方式、状态、来源。
- 状态标签：待执行、待确认、已确认、需调整、已完成、已跳过、已超时。
- 交互：
  - 点击任务查看详情。
  - 待确认任务展示“等待护工确认”。
  - 需调整任务展示护工原因和留言入口。

### 4.7 添加自定义任务

- 字段：任务名称、执行时间、执行方式、备注。
- 提交后：任务进入待确认状态。
- 页面提示：请以医护人员医嘱为准，系统仅用于陪护任务提醒和记录。
- 校验：
  - 任务名称、执行时间、执行方式必填。
  - 执行时间必须落在当前服务日期内。

### 4.8 陪护记录

- 页面结构：日期选择、筛选、时间线列表。
- 记录卡片字段：任务名称、计划时间、实际执行时间、执行状态、护工、备注、图片缩略图。
- 交互：
  - 点击图片打开预览。
  - 点击记录进入详情。
- 空状态：当天无记录时展示“暂无陪护记录”。
- 异常：图片无权限或过期时提示无法查看。

### 4.9 留言

- 留言列表：按服务单聚合展示最后一条留言和未读数。
- 留言详情：展示家属和护工消息气泡。
- 输入：文本输入框、发送按钮。
- 交互：
  - 发送失败保留文本并提示重试。
  - 有未读回复时底部导航显示红点。

### 4.10 评价

- 入口：服务结束后的首页提醒、我的评价。
- 字段：评分、评价标签、文字评价。
- 规则：同一服务单同一家属仅可提交一次。
- 提交后：展示评价成功页，可返回服务记录。

## 5. 护工端 H5 页面说明

### 5.1 登录与首次改密

- 登录组件：工号、密码、登录按钮。
- 首次改密：与家属端一致。
- 异常：账号停用时提示联系管理员。

### 5.2 今日

- 组件：日期、班次卡片、患者卡片、任务统计。
- 患者卡片字段：患者姓名、医院、科室、床号、护理注意事项、当前服务状态。
- 操作：进入任务清单、联系家属。
- 空状态：今日无排班时展示“今日暂无陪护安排”。

### 5.3 任务清单

- 分组：待确认、待执行、已完成、已超时。
- 任务卡片字段：任务名称、计划时间、执行方式、来源、状态。
- 操作：
  - 待确认任务：确认、建议调整、退回。
  - 待执行任务：提交记录。
  - 已完成任务：查看记录。
- 超时表现：超时任务置顶并展示红色状态。

### 5.4 自定义任务确认

- 展示：创建人、任务名称、执行时间、执行方式、备注。
- 操作：
  - 确认：任务变为已确认。
  - 建议调整：填写调整建议，任务变为需调整。
  - 退回：填写不可执行原因，通知家属。
- 校验：建议调整和退回必须填写原因。

### 5.5 提交执行记录

- 字段：执行状态、实际执行时间、备注、图片。
- 图片上传：最多 3 张，支持预览和删除。
- 提交成功：返回任务清单，任务变为已完成或已跳过。
- 提交失败：保留内容并提示重试。
- 已跳过：必须填写原因。

### 5.6 添加临时任务

- 入口：任务清单右上角。
- 字段：任务名称、执行时间、执行方式、备注。
- 提交后：直接生成任务和执行记录入口，同时家属端可见。

### 5.7 留言

- 列表：展示患者、最后留言、未读数。
- 详情：展示与当前服务相关的家属留言。
- 交互：回复文本；发送失败保留输入。

### 5.8 排班

- 视图：周视图和月视图。
- 字段：日期、班次、患者、医院、科室、床号、服务状态。
- 交互：点击排班查看患者与任务摘要。

### 5.9 我的

- 信息：姓名、工号、手机号、评分、服务次数。
- 操作：修改密码、退出登录。
- 我的评价：评价列表，仅展示评分、标签、内容和日期，不展示家属手机号。

## 6. 关键流程原型

### 6.1 家属申请护工

1. 家属登录并完成首次改密。
2. 首页选择患者。
3. 进入护工列表，筛选并选择护工。
4. 进入护工详情，点击申请陪护。
5. 填写服务日期、班次、需求说明。
6. 提交成功，申请状态为待审核。
7. 管理员确认后，家属首页展示当前服务卡片。

### 6.2 管理员审核与排班

1. 管理员在工作台看到待审核申请。
2. 进入申请详情，核对患者、家属、护工和需求。
3. 点击确认，选择最终护工、服务日期、班次和任务模板。
4. 系统校验护工班次冲突。
5. 确认成功后生成服务单、排班、固定任务和站内通知。

### 6.3 护工执行任务

1. 护工登录后进入今日页。
2. 点击患者卡片进入任务清单。
3. 选择待执行任务，进入提交记录页。
4. 填写实际执行时间、备注，上传图片。
5. 提交成功后任务状态变为已完成，家属记录时间线同步展示。

### 6.4 家属添加自定义任务

1. 家属进入任务计划页。
2. 点击添加任务，填写任务名称、执行时间、执行方式和备注。
3. 提交后任务状态为待确认。
4. 护工在任务清单待确认分组看到该任务。
5. 护工确认后任务生效；如建议调整，家属在任务详情和留言中看到原因。

### 6.5 留言与评价

1. 家属在服务中进入留言页发送咨询。
2. 护工在留言页查看并回复。
3. 服务结束后，家属收到站内待评价提醒。
4. 家属提交评分、标签和文字评价。
5. 管理员在评价管理中查看，必要时标记需回访。

## 7. 通用状态与反馈

| 场景 | 展示规则 |
| --- | --- |
| 加载中 | 列表和详情页展示骨架屏或加载提示 |
| 空数据 | 展示明确原因和下一步入口 |
| 表单错误 | 字段下方就近提示 |
| 网络失败 | 顶部或底部提示失败原因，保留用户输入 |
| 无权限 | 展示“暂无查看权限，请联系机构管理员” |
| 操作成功 | Toast 提示并刷新当前数据 |
| 关键确认 | 使用二次确认弹窗 |

## 8. 原型验收清单

- 管理员端每个一级菜单均有列表页和必要详情/弹窗说明。
- 家属端可完整走通“选护工-申请-查看任务-添加任务-查看记录-留言-评价”。
- 护工端可完整走通“看排班-确认自定义任务-提交记录-上传图片-回复留言”。
- 所有页面包含空状态、异常状态和主操作反馈。
- 首次改密、无授权患者、任务超时、图片上传失败、排班冲突、申请驳回均有明确页面表现。
