# 住院陪护系统 PRD

## 1. 文档信息

| 项目 | 内容 |
| --- | --- |
| 产品名称 | 住院陪护系统 |
| 服务对象 | 陪护机构、患者家属、护工 |
| 终端范围 | 管理员 PC 后台、患者家属 H5、护工 H5 |
| 版本 | V1.0 MVP |
| 业务模式 | 陪护机构自营平台；家属可在机构内自由选择护工；不包含支付功能 |
| 编写日期 | 2026-07-26 |

## 2. 背景与目标

### 2.1 背景

住院陪护服务存在信息不透明、任务执行难追踪、家属沟通成本高、机构排班管理依赖人工等问题。家属希望随时了解患者的陪护情况，护工需要清晰的任务安排与记录入口，陪护机构需要统一管理护工、患者、服务单、排班与评价。

### 2.2 产品目标

- 为陪护机构提供统一的服务管理后台，提升护工、患者、排班、任务和评价管理效率。
- 为患者家属提供护工选择、陪护申请、任务计划、执行记录、留言和评价能力。
- 为护工提供今日陪护对象、任务清单、任务执行记录、图片上传和留言回复能力。
- 建立“申请-确认-排班-执行-查看-评价”的可追溯闭环。

### 2.3 成功指标

- 家属可在 3 分钟内完成护工浏览、选择和陪护申请。
- 管理员可在 2 分钟内完成申请审核和排班确认。
- 护工可在 30 秒内完成单个任务记录提交。
- 家属可按患者、日期、任务类型查看完整陪护记录。
- 所有涉及患者信息、陪护记录、图片和留言的数据均有角色权限控制。

## 3. 用户角色

| 角色 | 核心诉求 | 主要权限 |
| --- | --- | --- |
| 管理员 | 管理机构服务、人和单据，处理异常和评价 | 管理护工、患者、家属、申请、排班、任务模板、记录、留言、评价、账号 |
| 患者家属 | 选择合适护工，查看陪护过程，补充个性化任务，评价服务 | 查看授权患者；发起陪护申请；查看护工；添加自定义任务；查看记录；留言；评价 |
| 护工 | 明确服务对象和任务，按时记录执行情况，回复家属留言 | 查看本人排班和患者基础信息；确认自定义任务；提交任务记录；上传图片；回复留言 |

## 4. 业务闭环

1. 管理员创建护工账号、患者信息、家属账号，并建立患者与家属的授权关系。
2. 家属使用手机号和初始密码登录，首次登录必须修改密码。
3. 家属选择已授权患者，浏览机构内可服务护工，提交陪护申请。
4. 管理员审核申请，确认护工、患者、服务日期、班次和任务模板，生成服务单与排班。
5. 护工使用工号和初始密码登录，首次登录必须修改密码。
6. 护工查看今日患者和任务清单，按执行时间完成吃饭、喝药、休息等固定任务记录。
7. 家属或护工可添加固定任务外的自定义任务；家属新增的自定义任务需护工确认后生效。
8. 护工提交任务执行结果，可上传图片和备注。
9. 家属查看陪护记录时间线，必要时留言咨询。
10. 服务完成后，家属对护工进行评价，管理员可查看和处理评价。

## 5. 功能范围

### 5.1 V1.0 范围内

- 管理员 PC 后台
  - 工作台：待审核申请、今日排班、超时任务、待处理留言、近期评价。
  - 护工管理：新增、编辑、停用、查看护工资料、服务状态、评分和历史服务。
  - 患者与家属管理：创建患者、创建家属账号、绑定授权关系。
  - 陪护申请审核：查看申请详情，确认、驳回、调整护工或时间。
  - 排班管理：按日期、护工、患者查看与调整排班。
  - 任务模板：维护固定任务模板，如吃饭、喝药、休息、翻身、如厕、陪检。
  - 陪护记录：按患者、护工、日期、任务状态检索记录。
  - 留言处理：查看家属与护工留言，支持管理员备注处理结果。
  - 评价管理：查看评分、文字评价，标记需回访评价。
  - 账号与权限：管理员账号、家属账号、护工账号、密码重置、账号停用。
- 家属 H5
  - 登录、首次修改密码、退出登录。
  - 选择已绑定患者，查看患者当前服务状态。
  - 浏览护工列表和详情，筛选可服务护工。
  - 提交陪护申请，查看申请状态。
  - 查看任务计划与陪护记录时间线。
  - 添加自定义任务，填写执行时间、执行方式和备注。
  - 发送留言，查看护工回复。
  - 服务结束后提交评价。
- 护工 H5
  - 工号密码登录、首次修改密码、退出登录。
  - 查看今日陪护患者与排班。
  - 查看任务清单，按任务提交执行记录。
  - 确认、退回或建议调整家属新增的自定义任务。
  - 添加临时任务记录。
  - 上传陪护图片，填写备注。
  - 回复家属留言。

### 5.2 V1.0 范围外

- 在线支付、退款、发票。
- 视频监控、实时定位、实时音视频通话。
- 医院 HIS/EMR 系统对接。
- 短信、微信模板消息、电话外呼。
- 护工薪资结算和财务报表。
- 强实名、人脸识别、电子签章。

## 7. 状态流转

### 7.1 陪护申请状态

| 状态 | 说明 | 可操作角色 |
| --- | --- | --- |
| 待审核 | 家属已提交申请，等待管理员处理 | 管理员 |
| 已确认 | 管理员确认护工与排班，生成服务单 | 管理员、家属、护工 |
| 已驳回 | 管理员拒绝申请并填写原因 | 管理员、家属 |
| 已取消 | 家属在确认前取消申请 | 家属 |

### 7.2 服务单状态

| 状态 | 说明 |
| --- | --- |
| 待开始 | 已排班但未到服务日期 |
| 服务中 | 当前处于服务日期内 |
| 已结束 | 服务日期结束或管理员手动结束 |
| 已中止 | 管理员因异常中止服务 |

### 7.3 任务状态

| 状态 | 说明 |
| --- | --- |
| 待执行 | 任务已生效，尚未到提交或未提交 |
| 待确认 | 家属新增的自定义任务，等待护工确认 |
| 已确认 | 护工确认自定义任务，可进入执行 |
| 需调整 | 护工认为时间或方式不可执行，需留言协商 |
| 已完成 | 护工已提交执行记录 |
| 已跳过 | 护工标记未执行并填写原因 |
| 已超时 | 超过计划执行时间仍未提交 |

## 8. 详细需求

### 8.1 登录与账号

- 管理员可创建家属账号，登录账号为手机号。
- 管理员可创建护工账号，登录账号为工号。
- 管理员设置初始密码，用户首次登录后必须修改密码才能进入业务页面。
- 密码要求：8-20 位，包含字母和数字。
- 连续 5 次登录失败后锁定 15 分钟。
- 账号停用后不可登录，已登录用户下次请求时退出。

### 8.2 家属患者绑定

- 一个患者可绑定多个家属。
- 一个家属可绑定多个患者。
- 家属只能查看已授权患者的信息、任务、记录、留言和评价。
- 管理员可新增、停用或恢复绑定关系。
- 绑定停用后，家属不可继续查看该患者历史与新增数据。

### 8.3 护工展示与申请

- 家属端护工列表展示头像、姓名、性别、经验年限、擅长、评分、服务状态。
- 支持按性别、评分、服务状态筛选。
- 护工详情展示个人简介、服务经验、擅长护理、近期评价、可申请状态。
- 家属提交申请需选择患者、护工、服务开始日期、服务结束日期、班次、需求说明。
- 提交后生成“待审核”申请并通知管理员。
- 管理员确认时可调整护工、日期和班次；调整后家属端展示最终确认结果。

### 8.4 排班管理

- 管理员按日期视图查看护工排班。
- 同一护工同一日期同一班次不可重复排班。
- 排班至少关联一个患者、一个护工、一个服务单。
- 调整排班后，家属和护工端同步展示新排班，并生成站内通知。
- 已结束服务单不可新增排班。

### 8.5 任务模板

- 管理员维护机构级固定任务模板。
- 固定任务模板字段包括任务名称、任务类型、默认执行时间、执行要求、是否启用。
- 新服务单生成时，系统按模板初始化患者任务计划。
- 已停用模板不再生成新任务，但不影响历史任务和已生成任务。

### 8.6 自定义任务

- 家属可为已授权且处于服务中的患者新增自定义任务。
- 家属填写任务名称、执行时间、执行方式、备注。
- 家属新增后任务状态为“待确认”，护工需确认、退回或建议调整。
- 护工确认后任务生效并进入任务清单。
- 护工退回或建议调整时需填写原因，系统生成留言并通知家属。
- 护工也可新增临时任务，新增后直接进入本人任务清单和家属记录视图。
- 自定义任务不得替代医嘱执行确认，页面需提示“请以医护人员医嘱为准”。

### 8.7 执行记录

- 护工在任务详情页提交执行结果。
- 执行结果包括已完成、已跳过。
- 已完成记录需填写实际执行时间，可选备注和图片。
- 已跳过记录必须填写原因。
- 图片支持最多 3 张，单张大小上限 10 MB，格式支持 JPG、PNG。
- 提交失败时保留已输入内容并提示重试。
- 超过计划执行时间 30 分钟未提交时，任务标记为已超时，并生成站内通知。

### 8.8 陪护记录查看

- 家属端按日期展示陪护记录时间线。
- 每条记录展示任务名称、计划时间、实际执行时间、执行状态、护工、备注和图片。
- 支持按任务类型和状态筛选。
- 管理员端支持按患者、护工、日期、状态检索。
- 图片查看需鉴权，未授权用户不可访问图片原图。

### 8.9 留言

- 家属可针对患者当前服务单发起留言。
- 护工可回复与本人服务单相关的留言。
- 管理员可查看留言，并可添加内部处理备注。
- 留言支持文本，V1.0 不支持语音、视频、文件。
- 未读留言在各端展示站内提醒。

### 8.10 评价

- 服务单结束后，家属可评价护工。
- 评价字段包括评分、评价标签、文字评价。
- 每个服务单每个家属最多提交 1 次评价。
- 管理员可查看评价并标记“需回访”。
- 护工端可查看自己的评价列表，但不展示家属手机号。

### 8.11 站内通知

- 通知类型包括申请待审核、申请确认/驳回、排班变更、任务待确认、任务超时、留言未读、服务结束待评价。
- 通知支持已读/未读。
- V1.0 仅站内通知，不接入短信或微信通知。

## 9. 权限规则

| 数据/操作 | 管理员 | 家属 | 护工 |
| --- | --- | --- | --- |
| 护工资料管理 | 全部 | 仅查看可展示字段 | 查看本人 |
| 患者基础信息 | 全部 | 仅授权患者 | 仅本人排班患者 |
| 家属绑定 | 全部 | 查看本人授权 | 无 |
| 陪护申请 | 全部处理 | 创建和查看本人申请 | 查看已确认且与本人相关 |
| 排班 | 全部管理 | 查看授权患者排班 | 查看本人排班 |
| 任务模板 | 全部管理 | 查看生成后的任务 | 查看生成后的任务 |
| 自定义任务 | 全部查看 | 创建和查看授权患者任务 | 确认与本人服务相关任务 |
| 执行记录 | 全部查看 | 查看授权患者记录 | 创建和查看本人记录 |
| 留言 | 全部查看和备注 | 创建和查看相关留言 | 回复本人相关留言 |
| 评价 | 全部查看和标记 | 创建本人相关评价 | 查看本人评价 |

## 10. 非功能需求

- 移动端页面首屏加载目标小于 3 秒。
- 常用列表支持分页或下拉加载。
- 关键操作需有二次确认，包括驳回申请、停用账号、中止服务单。
- 敏感数据传输使用 HTTPS。
- 密码加密存储，不保存明文密码。
- 图片访问需通过鉴权 URL 或后端鉴权接口。
- 关键操作保留审计日志，包括登录、密码修改、排班调整、任务记录提交、账号停用。
- 系统保留数据导出能力作为后台扩展点，V1.0 可不提供前端入口。

## 11. 隐私与合规要求

- 患者姓名、医院、科室、床号、护理注意事项、任务记录、图片和留言可能涉及个人信息和医疗健康类敏感个人信息。
- 系统应遵循最小必要原则，仅收集实现陪护服务所需字段。
- 在家属端首次登录或绑定患者时展示隐私告知与授权确认。
- 用户应可通过机构客服或管理员申请更正、删除、撤回授权、注销账号。
- 管理员、护工不得查看与其职责无关的患者数据。
- 参考依据：
  - 《中华人民共和国个人信息保护法》：https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm
  - 《网络数据安全管理条例》：https://www.mee.gov.cn/zcwj/gwywj/202410/t20241003_1087417.shtml

## 12. 验收标准

- 三端页面和功能覆盖本 PRD 的 V1.0 范围。
- 家属申请护工后，管理员可完成确认并生成护工排班。
- 护工可看到今日任务，并完成固定任务和自定义任务的执行记录。
- 家属新增自定义任务后，护工端出现待确认任务。
- 家属可看到执行记录时间线、图片、备注和任务状态。
- 首次登录未修改密码时，家属和护工不可进入业务页面。
- 未绑定患者的家属无法查看患者信息和陪护记录。
- 图片上传失败、任务超时、申请驳回等异常场景有明确提示和状态。
