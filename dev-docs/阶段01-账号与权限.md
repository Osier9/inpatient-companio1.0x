# 阶段 01 账号与权限开发文档

## 1. 开发目标

实现管理员、家属、护工三类用户的登录、退出、刷新 Token、首次改密、普通改密、账号启停、密码重置和角色权限拦截。

## 2. 输入与依赖

- 依赖阶段：阶段 00。
- 需求来源：FAM-001、CAR-001、ADM-011、EX-002。
- 关联规格：`specs/05-api-design/接口设计.md`、`specs/07-backend-design/后端设计.md`。

## 3. 数据库开发

新增迁移：`V002__auth_user.sql`。

创建表：

- `sys_user`

关键索引：

- `uk_sys_user_login_account(login_account, deleted)`
- `idx_sys_user_role(role)`
- `idx_sys_user_status(account_status)`

初始化数据：

- 默认管理员账号。
- 默认密码必须设置为 `INITIAL` 状态，首次登录强制修改。

## 4. 后端开发

### 4.1 包结构

```text
auth/
  controller/
  application/
  domain/
  repository/
  dto/
  entity/
```

### 4.2 核心类

| 类 | 职责 |
| --- | --- |
| `AuthController` | 登录、刷新、退出、改密 |
| `UserAdminController` | 管理员重置密码、启停账号 |
| `AuthApplicationService` | 登录流程、Token 发放、失败计数 |
| `PasswordService` | 密码强度校验、BCrypt 加密 |
| `TokenService` | JWT 和 Refresh Token 管理 |
| `PermissionService` | 角色权限校验 |
| `CurrentUserHolder` | 当前登录用户上下文 |

### 4.3 业务规则

- 家属使用手机号登录。
- 护工使用工号登录。
- 管理员使用后台账号登录。
- 初始密码登录后，接口返回 `mustChangePassword=true`。
- 首次改密前只能访问当前用户信息、退出、首次改密接口。
- 密码规则：8-20 位，包含字母和数字。
- 登录失败 5 次锁定 15 分钟。
- 停用账号不可登录。

## 5. API 开发

必须实现：

- `POST /api/common/auth/login`
- `POST /api/common/auth/refresh`
- `POST /api/common/auth/logout`
- `GET /api/common/auth/me`
- `POST /api/common/auth/change-initial-password`
- `POST /api/common/auth/change-password`
- `POST /api/admin/users/{id}/reset-password`
- `PATCH /api/admin/users/{id}/status`

错误码：

- `AUTH_LOGIN_FAILED`
- `AUTH_ACCOUNT_LOCKED`
- `AUTH_INITIAL_PASSWORD_REQUIRED`
- `AUTH_FORBIDDEN`
- `AUTH_ACCOUNT_DISABLED`

## 6. 前端开发

### 6.1 管理端

- `/admin/login`
- `/admin/change-initial-password`
- `/admin/no-permission`
- 账号管理入口可先放在系统设置中。

### 6.2 家属端

- `/family/login`
- `/family/change-initial-password`

### 6.3 护工端

- `/caregiver/login`
- `/caregiver/change-initial-password`

### 6.4 路由守卫

- 无 token：跳登录页。
- 有 token 但角色不匹配：跳无权限页。
- `passwordStatus=INITIAL`：跳首次改密页。

## 7. 联调步骤

1. 管理员用初始密码登录。
2. 前端跳首次改密页。
3. 改密成功后进入后台。
4. 创建一个家属账号和一个护工账号。
5. 家属和护工分别登录，验证首次改密。
6. 使用家属 Token 访问后台接口，确认返回 403。

## 8. 验收标准

- 三类角色可登录。
- 首次登录必须改密。
- 账号停用后不可登录。
- 连续 5 次错误密码锁定 15 分钟。
- 角色越权访问被拦截。
