## 开发约定

- 后端：Java 17、Spring Boot 3.x、MyBatis Plus、MySQL 8、Redis 7、MinIO。
- 前端：Vue 3、TypeScript、Vite、Element Plus、Vant、Pinia、Axios。
- 后端包根路径建议：`com.inpatientcompanio`。
- 管理端 API 前缀：`/api/admin`。
- 家属端 API 前缀：`/api/family`。
- 护工端 API 前缀：`/api/caregiver`。
- 通用 API 前缀：`/api/common`。
- 每个阶段完成后必须补齐：数据库迁移、后端接口、前端页面、权限校验、单元/接口测试、冒烟验收。
