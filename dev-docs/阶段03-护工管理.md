# 阶段 03 护工管理开发文档

## 1. 开发目标

实现护工资料、护工工号账号、服务状态、家属端护工展示和护工端本人资料。

## 2. 输入与依赖

- 依赖阶段：阶段 01。
- 需求来源：ADM-002、FAM-003、FAM-004、CAR-009 的基础资料部分。

## 3. 数据库开发

新增迁移：`V004__caregiver.sql`。

创建表：

- `caregiver_profile`

关键索引：

- `uk_caregiver_employee_no(employee_no, deleted)`
- `uk_caregiver_user(user_id, deleted)`
- `idx_caregiver_service_status(service_status)`
- `idx_caregiver_rating(rating_avg)`

## 4. 后端开发

### 4.1 核心类

| 类 | 职责 |
| --- | --- |
| `CaregiverAdminController` | 后台护工维护 |
| `FamilyCaregiverController` | 家属端护工列表和详情 |
| `CaregiverProfileController` | 护工本人资料 |
| `CaregiverApplicationService` | 新增护工并创建账号 |
| `CaregiverQueryService` | 护工查询展示 |

### 4.2 业务规则

- 工号唯一。
- 新增护工时同步创建 `CAREGIVER` 用户。
- 停用护工账号后不可登录，但历史业务数据保留。
- 家属端只展示可公开字段，不展示手机号等内部字段。
- 护工评分和服务次数本阶段可维护字段，后续由评价模块刷新。

## 5. API 开发

必须实现：

- `GET /api/admin/caregivers`
- `POST /api/admin/caregivers`
- `GET /api/admin/caregivers/{id}`
- `PUT /api/admin/caregivers/{id}`
- `PATCH /api/admin/caregivers/{id}/service-status`
- `GET /api/family/caregivers`
- `GET /api/family/caregivers/{id}`
- `GET /api/caregiver/profile/me`

## 6. 前端开发

### 6.1 管理端

- 护工列表：
  - 筛选：姓名/工号、性别、服务状态、账号状态、评分。
  - 操作：新增、编辑、查看、重置密码、停用/启用。
- 护工详情：
  - 基础资料、服务统计、评价摘要、当前服务状态。

### 6.2 家属端

- 护工列表：
  - 护工卡片展示头像、姓名、经验、擅长、评分、服务状态。
  - 支持筛选和搜索。
- 护工详情：
  - 展示简介、经验、擅长、近期评价摘要、可申请状态。

### 6.3 护工端

- 我的页面展示姓名、工号、手机号、评分、服务次数。

## 7. 联调步骤

1. 管理员新增护工并设置初始密码。
2. 护工用工号登录并首次改密。
3. 家属端查看护工列表和详情。
4. 管理员停用护工账号。
5. 护工再次登录失败。

## 8. 验收标准

- 工号重复不能保存。
- 家属端能看到护工展示字段。
- 护工端能查看本人资料。
- 停用护工不可登录。
